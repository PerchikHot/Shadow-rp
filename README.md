# Shadow RP

Shadow RP — AI roleplay chat for Android and Windows. **Not a Minecraft mod.**

## Android
The Android app is in `app/`. Its APK is built by
[Android workflow](.github/workflows/android.yml).

## Windows RP chat (new)
The actual desktop chat client is `desktop/rp_chat.py`, built into
`ShadowRP.exe` by [Windows AI Chat workflow](.github/workflows/rp-windows.yml).

Features:
- Character cards, editable scenario, manually pinned memory and per-character chat history.
- Local JSON history in `%APPDATA%\\ShadowRP\\chats.json`.
- Optional OpenAI-compatible chat-completions API (including localhost).
- Model, API base URL and key supplied in the UI; API key is not stored.
- Network errors do not delete user messages; HTTP redirects are blocked for API keys.
- Only the last 30 dialogue messages are sent, alongside the persistent character, scenario and pinned memory.
- Pinned memory is edited by the user; no unverified personal facts are generated or saved automatically.
- **Поиск и откат диалога** on Windows: search the entire character history, choose a player message, and explicitly confirm removing later turns. A separate `chats-rewind-checkpoint.json` archive is saved next to `chats.json` before the change, and can be imported to restore the prior conversation. No AI reply is generated by rewinding.

Run from source: `python desktop/rp_chat.py`.
An AI endpoint must be configured to receive AI responses; no model is bundled.
The Windows workflow must pass before the EXE can be treated as a verified build.

## Transfer characters and stories between Android and Windows

Both clients use the same **Shadow RP JSON** archive:
`{"characters":{"Name":{"description":"...","scenario":"...","memory":"...","appearance":"...","greeting":"...","protocol":"...","messages":[{"role":"user","content":"..."}]}}}`.

- **Android:** Profile → Export characters and stories / Import characters and stories.
  The system file picker is used; no storage permission or cloud upload is needed.
  Import shows the number of matching character names and asks before overwriting
  those cards and chat histories. Other Android characters are retained.
- **Windows:** Export chats / Import chats. Windows import asks for confirmation
  and merges characters by name. Matching cards and their histories are replaced
  only after confirmation; unrelated Windows characters are kept. Export first.
  Windows preserves and lets you edit appearance, greeting and protocol fields
  as well as description, scenario and manually pinned memory.
- Import limits: 8 MiB, 200 characters, 10,000 messages per character,
  20,000 characters per message. Only user/assistant messages are portable.
  API keys, GGUF models, avatars, device settings and credentials are never
  included. This is **manual transfer**, not live synchronization.
- Android backup codec regression tests run in the APK workflow before build.

The old `forge/` directory and `desktop/shadow_launcher.py` are unrelated

Their workflows have been disabled. They are **not** Shadow RP deliverables.

## Windows dialogue rewind verification

1. Export an archive, then open **Поиск и откат диалога** for a character with several exchanges.
2. Search for a word from an older turn; results show the newest matching turns first.
3. Select a **player** turn and confirm rewind. The selected turn remains as the last message, ready for **Повторить ответ**.
4. Verify other characters and their conversations are unchanged. Import `%APPDATA%\\ShadowRP\\chats-rewind-checkpoint.json` to restore the previous history if needed.
5. On Android, open a character chat and tap **⌕ Поиск и откат переписки**. Search is case-insensitive and shows up to 50 recent matches. Only player turns can be selected for rewind. Confirm the change; the selected player turn stays in the chat, and **↻ Повторить ответ ИИ** can generate a new continuation.
6. Before Android changes the chat, it atomically saves a private JSON checkpoint for that character. The chat then shows **↶ Восстановить переписку до отката**. Restoration requires confirmation and changes only the selected character; other characters and their pinned memories remain intact.
7. Android checkpoints are local app-private files, not automatic cloud backups; uninstalling the app may delete them. Export a full portable JSON archive before major changes. Rewinding is disabled while the model is generating. Android on-device UI and recovery still require real-device verification.
